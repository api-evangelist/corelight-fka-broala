# Corelight (fka Broala)

> Corelight is a network detection and response (NDR) company founded by the creators of the open-source Zeek (formerly Bro) network security monitor. Its Open NDR platform transforms network traffic into high-fidelity evidence — using Zeek and Suricata engines — for threat detection, investigation, hunting, and response across on-premises, cloud, and hybrid environments. Corelight Sensors can be configured and operated remotely through a RESTful API; the public, open-source surface for that API is the corelight-client command-line tool.
